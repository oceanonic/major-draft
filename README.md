# Major Draft

A historical Counter-Strike Major draft game.

## GitHub Pages

This repository is intended to be published as a static GitHub Pages site. The production game is a self-contained `index.html` file.

## Deployment

1. In **Settings → Pages**, choose **Deploy from a branch**.
2. Select `main` and `/ (root)`.
3. Save.
4. After GitHub publishes the site, use the generated Pages URL.

For a custom domain, add the domain under **Settings → Pages → Custom domain**, then configure the DNS records required by GitHub Pages.

## Production version

V27 is the current production build. The repository should contain `index.html` at the root; ZIP archives are not used by GitHub Pages as the site entry point.
